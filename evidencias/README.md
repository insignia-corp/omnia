# Evidências

Saídas brutas de eval, testes e medições. Os arquivos gerados aqui ficam fora do git (ver `.gitignore`), exceto este README e o que for promovido de propósito para a banca (hoje, as capturas de tela do painel). O relatório versionado de cada rodada do eval vai para `docs/avaliacoes/`; aqui fica só a saída bruta.

Convenção de nome: `AAAA-MM-DD-<comando>.txt` para saída de comando; o `npm run eval` grava `AAAA-MM-DD-eval-<modo>-<hora>.json`. Os números que importam são destilados para `docs/ESTADO.md` com a data e o comando que os gerou.

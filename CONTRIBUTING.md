# Como contribuir

1. Atualize a `develop`: `git checkout develop && git pull`
2. Crie uma branch: `git checkout -b feature/minha-feature`
3. Faça commits pequenos e descritivos (ex.: `feat: adiciona login`, `fix: corrige validação`)
4. Envie: `git push -u origin feature/minha-feature`
5. Abra um Pull Request para `develop` e peça revisão de pelo menos 1 pessoa
6. Releases: PR de `develop` → `main`

## Prefixos de commit

`feat`, `fix`, `docs`, `refactor`, `test`, `chore`

# Omnia

Descrição do projeto.

## Estrutura

```
.
├── .github/          # Templates de issue/PR e CODEOWNERS
├── docs/             # Documentação
├── src/              # Código-fonte
└── tests/            # Testes
```

## Fluxo de trabalho

- `main` — código estável (protegida, só via PR)
- `develop` — integração das features
- `feature/<nome>`, `fix/<nome>` — criadas a partir de `develop`

Veja [CONTRIBUTING.md](CONTRIBUTING.md).
